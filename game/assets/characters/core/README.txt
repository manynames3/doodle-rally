CAT RACERS — CORE GAMEPLAY ASSET PACK

Eight individual character folders, each with transparent normalized selection art and separated animation frames.
Per character: idle (4), drive (6), boost (3), brake (3), select_sprite, and portrait.
Animation frames are 640x640 RGBA PNGs with consistent cast scale, shared ground baseline, and generous transparent padding.
Selection sprites use the side-view drive pose to keep kart silhouette and wheel count clean and consistent; portraits are separately normalized.
Shared_VFX contains standalone dust, boost flame, and skid smoke effects. No backgrounds are included.
See asset_manifest.json for frame counts and normalization metadata.
