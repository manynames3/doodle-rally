# Sources and asset notices

The user requested a standalone 3D rebuild of Doodle Rally from the original `build-the-first-playable-mac-version` project dated September 9, 2026. That repository was inspected read-only. Only Doodle Rally's three original synthesized music loops, their generator, the shared Kalam font and applicable license notices were copied. Fighting gameplay, fighter art, original settings and combat data are not included.

The supplied September 13 renderings guide the cat roster, clubhouse menus, course themes, HUD and title composition. New raster menu backgrounds and course postcards were created using the built-in image generation tool. The active title background is an edit of the user's latest title reference with baked interface elements removed. Every actual title, button and selection state is native Godot UI. Exact prompts and output names are recorded in `game/assets/art/README.md`.

All karts, cat drivers, voxel drivers, track surfaces, forests, cliffs, tunnels, bridges, waterfalls, desk props, neon buildings, item objects and effects use original procedural meshes or shaders. Version 1.1 adds generated dirt, limestone, timber and fir-branch material images, documented in game/assets/world/world_material_prompts.md. The fur shader is opaque; it does not use alpha shells or fade racers. Cat HUD portraits are rendered from the actual game models. Menu character/Garage previews render the same models used during races. Course card illustrations are art direction postcards rather than literal screenshots of the circuit geometry.

Minecraft Racing is a user-requested Minecraft-inspired mode in this private prototype. Minecraft, its character names and related trademarks belong to their respective owners; this is not an official Mojang or Microsoft product. No Minecraft game files, textures, models, music or recordings were copied. No Nintendo/Mario Kart assets are included.

The three music tracks were generated by Doodle Rally's original `game/assets/music/generate_music.py`. NumPy is only required to regenerate those WAV files. Gameplay effects and engine sounds are newly synthesized by `rally_sound.gd`; no external recordings or samples are used.

Kalam is by Indian Type Foundry under the SIL Open Font License; its notice is in `docs/licenses/KALAM_OFL.txt`. Godot and bundled components retain their notices in `docs/licenses/`.

Barlow Condensed ExtraBold Italic is by Jeremy Tribby under the SIL Open Font License. It supplies the racing HUD numerals; its notice is in `docs/licenses/BARLOW_OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed.
