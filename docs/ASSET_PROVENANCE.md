# Sources and asset notices

The user requested a standalone 3D rebuild of Doodle Rally from the original `build-the-first-playable-mac-version` project dated September 9, 2026. That repository was inspected read-only. The initial extraction copied Doodle Rally’s three original synthesized music loops, their generator, the shared Kalam font and applicable license notices. The studio logo was subsequently copied at the user’s request, as described below. Fighting gameplay, fighter art, original settings and combat data are not included.

The supplied September 13 renderings guide the cat roster, clubhouse menus, course themes, HUD and title composition. New raster menu backgrounds and course postcards were created using the built-in image generation tool. Versions 1.2 and 1.3 use `title_race_v3.png`, derived from the user's title composition and supplied cat photographs; earlier title concepts remain historical source assets and are excluded from the current Mac export. Every actual title, button and selection state is native Godot UI. Exact prompts and output names are recorded in `game/assets/art/README.md`.

The user supplied pet photographs to personalize the main tuxedo **Zizi** in slot 0 and the calico **Mak-Doong** in slot 6. Their markings guide the sculpted procedural 3D models and derived artwork; Mak-Doong's golden halo was added at the user's request. Original photographs are kept outside the distributable project. Character indices remain stable. Version 1.2 used the temporary labels You/Tuxedo and Angel; 1.3 uses the names supplied by the user. The eight current cats include Nori in slot 7.

The **BenJam Games** studio splash uses the user's supplied `benjam_games.png`, copied unchanged from the original project's assets at the user's request. It is displayed briefly before the title menu. The new fur microdetail and alpine limestone textures were generated for version 1.3; prompts are recorded in `game/assets/characters/README.md` and `game/assets/art/README.md`.

Version 1.3.3 integrates the user's **Cat_Racers_Core_Assets.zip** as unchanged individual transparent PNGs in `game/assets/characters/core/`. The eight `selection/select_sprite.png` images appear in Character Select; separate portraits appear there and in the race HUD. The Garage plays each character's numbered idle, drive, boost, and brake frames and layers `Shared_VFX` dust, flame, and smoke independently. The pack manifest and original README files are retained with the extracted art. Source composite sheets are not included. The prior sheet-derived front cutouts and generated cat HUD portraits were removed to avoid redundant packaging. Track Select retains its rear-view cutouts because this pack has only side views.

Version 1.3.6 adds the user's **Cat_Racers_2D_Turntable_Asset_Pack_1024** individual transparent frames under `game/assets/characters/turntable/<character>/view_00.png` through `view_15.png`. All 128 project PNGs were byte-checked against the supplied pack. They retain their 1024×1024 source canvases and are swapped as separate images only in the selected Character Select preview; they are not flattened, upscaled from the 512px preview pack, or used to replace gameplay models. Godot imports the source PNGs normally for runtime display.

Race karts, cat drivers, voxel drivers, track surfaces, forests, cliffs, tunnels, bridges, waterfalls, desk props, neon buildings, item objects and 3D race effects use original procedural meshes or shaders. Version 1.1 adds generated dirt, limestone, timber and fir-branch material images, documented in game/assets/world/world_material_prompts.md. The fur shader is opaque; it does not use alpha shells or fade racers. Course card illustrations are art direction postcards rather than literal screenshots of the circuit geometry.

Minecraft Racing is a user-requested Minecraft-inspired mode in this private prototype. Minecraft, its character names and related trademarks belong to their respective owners; this is not an official Mojang or Microsoft product. No Minecraft game files, textures, models, music or recordings were copied. No Nintendo/Mario Kart assets are included.

The three music tracks were generated by Doodle Rally's original `game/assets/music/generate_music.py`. NumPy is only required to regenerate those WAV files. The generator now writes evolving 64-bar arrangements (about 118–132 seconds) and blends the final 0.9 seconds into the opening for a smoother loop. Gameplay effects and engine sounds are newly synthesized by `rally_sound.gd`; no external recordings or samples are used.

Kalam is by Indian Type Foundry under the SIL Open Font License; its notice is in `docs/licenses/KALAM_OFL.txt`. Godot and bundled components retain their notices in `docs/licenses/`.
