# Doodle Rally — Cat Racers 1.3.6

Character Select now uses the supplied 1024×1024 transparent turntable frames for all eight cats. Only the selected racer cycles; its 16 images swap directly in order over six seconds, while the other seven cards remain still on `view_00.png`. The shared source canvas keeps framing and baseline consistent. Reduced Motion holds the front-facing image. These are stepped 2D views, not continuous 3D models.

Desktop Dojo's paper sheet previously shared its top height with the wooden tabletop, allowing depth-buffer z-fighting as the chase camera moved. The sheet now sits 0.2 m above the deck. The earlier graph-paper strips that shimmered at shallow angles remain removed.

All 128 turntable PNGs match the supplied source pack byte-for-byte. The seven source test suites passed, including 517 core-asset checks, the Desktop Dojo surface-clearance regression, six course/mode world builds, and three temporal collision replays. The native Universal Mac app passed 34 packaged-app cases: all eight selected-cat previews, three timed turntable phases, the menu/garage/course screens, six race screens, and four 12-second driving runs. The Desktop Dojo drive reported 8.465 ms median and 9.662 ms p95 frame intervals during this run. See `docs/test-results/1.3.6/` and `screenshots/1.3.6/`.

The app uses the existing Godot 4.7.2 Universal runtime with the new exported project pack, updated bundle version, and local ad-hoc signature. It runs on Apple Silicon and Intel Macs. The bundle is not Apple-notarized; macOS may ask the user to approve opening it when downloaded.
