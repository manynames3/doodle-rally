# Doodle Rally — Cat Racers 1.3.7

This build polishes the racers' rear-facing fur and gives the two stylized courses clearer, more playful scenery. Desktop Dojo now uses a calm mountain horizon instead of a wraparound panorama that competed with the tabletop track. Chunkier, more widely spaced rails, a pencil-pit landmark, handwritten course signs, and two ruler gates add visual rhythm and small jokes as the race progresses. Glitch Core keeps its neon city panorama, with its course-specific skyline and lighting intact.

The race model, saved racer identities, controls, collision behavior, and course rules remain the same. Character Select continues to use the supplied 1024×1024 transparent frames: one image per racer card, with only the selected cat stepping through 16 views over six seconds. This is a 16-step 2D turntable, not continuous 3D rotation.

## Verification

- Godot 4.7.2 imported and exported the project as a Universal macOS app for Apple Silicon and Intel.
- All seven source suites passed: 863 counted functional checks, six cat/Minecraft course builds, and three temporal collision replays with no assertion violations.
- All 34 packaged-app cases passed, including all eight selected-cat previews, three turntable phases, menu and Garage states, both rosters, each course, and four 12-second drives.
- The four native drives ran at a 16.67 ms median frame interval (60 fps); their p95 intervals ranged from 16.67 to 16.81 ms. These are short samples on this Mac, not a sustained performance guarantee.
