## Rebuild and rerun

Use standard Godot 4.7.2 with matching Mac export templates. From the project root:

```sh
python3 tools/test.py --godot /path/to/Godot.app/Contents/MacOS/Godot
python3 tools/export_mac.py --godot /path/to/Godot.app/Contents/MacOS/Godot --template /path/to/macos.zip
python3 tools/test_release.py
```

`tools/test.py` writes temporary collision telemetry to `test-output/`. The native release runner uses `--qa-character=0` and `--qa-character=6` to exercise both custom cats, plus Minecraft mode. QA isolates player preferences. The export helper writes only the 1.2 app/ZIP paths and restores portable template settings afterward.

The game remains single-player. The app is signed locally rather than Apple-notarized. Intel Mac hardware, physical controller hardware/rumble, external displays and long-session performance remain untested. Asset sources and licenses are in `docs/ASSET_PROVENANCE.md`.
