# Doodle Rally — Cat Racers 1.3.5

Character Select now keeps the supplied core-pack artwork when a racer is selected. Previously, the selected card replaced its current art with an older procedural 3D cat and kart, which made Zizi look different from the latest asset. The selected card now spins its own high-resolution transparent `select_sprite.png` on a simple unshaded turntable, still completing one smooth 360° rotation every six seconds. The normal card image is hidden during the preview so each racer appears only once.

The core pack provides one selection angle per cat, not full turnarounds. The back half of the spin therefore shows that supplied cutout from its reverse side, rather than a separately modeled rear view. The seven non-selected racers and gameplay racer models are unchanged.

Verification: 574 functional checks across seven source suites, six course/mode world builds, three temporal collision replays, a signed Universal macOS export, and 27 native packaged-app cases with fresh captures. The turntable checks cover source-art selection, six-second timing, constant angular speed, loop boundary, Reduced Motion, and switching characters. The native captures include the front, quarter-, half-, and three-quarter-turn poses. See `docs/test-results/1.3.5/`, `screenshots/1.3.5/`, and [`BUILD_STATUS.md`](../../BUILD_STATUS.md). The app is locally signed and is not Apple-notarized.
