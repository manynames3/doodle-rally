# Doodle Rally — Cat Racers 1.3.4

Character Select now shows one image for each cat. The focused racer's supplied cutout is replaced by the existing 3D cat and kart preview, which turns smoothly through a complete 360° every six seconds and continues without stopping. The preview follows the current selection. Seven unselected racers keep their supplied transparent artwork. Reduced Motion holds the preview still.

The native release checks cover both the front-facing pose and a half-turn, and the menu's automated test checks the full-period return, steady rotation, loop boundary, and switching the selected racer.

The turntable's unit tests check its six-second period, steady angular speed, loop boundary, reduced-motion behavior, and selection changes; the packaged tests capture the front, quarter-, half-, and three-quarter-turn poses.
