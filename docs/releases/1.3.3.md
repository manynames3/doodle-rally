# Doodle Rally — Cat Racers 1.3.3

This release integrates the supplied **Cat Racers Core Gameplay Asset Pack** without changing race controls, AI, course logic, or saved racer indices. The pack's eight individual character folders and `Shared_VFX` are extracted unchanged into `game/assets/characters/core/`; Godot `.png.import` settings keep the transparent art lossless, mipmapped, and alpha-border safe. No composite asset sheets are used.

Character Select now shows each racer's `selection/select_sprite.png` on a common 166×190 layout and uses the matching portrait. The same portraits identify cats in the race HUD. The Garage plays the numbered idle, drive, boost, and brake frames in order for all eight cats; dust, blue boost flame, and skid smoke remain independent effect layers. The source asset manifest, instructions, and character identities remain with the imported files. Redundant sheet-derived front sprites and former cat HUD portraits were removed, while Track Select retains its eight rear-view cutouts.

The pack contains side-view kart frames only. The chase-camera race therefore continues to render the existing 3D cats and karts, and the rear-facing Track Select still uses the established rear art. This avoids a second kart or ghost wheels in the playable scene. A future rear-view frame pack or rigged 3D models would be needed to use the new 2D frames during racing itself.

Verification: ZIP integrity, per-character asset and alpha geometry checks, all seven source regression suites, six course/mode world builds, three collision replays, Godot import/export, signature verification, and native packaged-app screenshots. Character Select and Garage captures were inspected for all eight racers' lineup alignment, Zizi's relative size, clean cutout edges, and separate boost/brake effects. See `docs/test-results/1.3.3/`, `screenshots/1.3.3/`, and `BUILD_STATUS.md` for the recorded outputs. The Universal Mac app is locally signed rather than Apple-notarized.
