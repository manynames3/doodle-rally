# Doodle Rally — Cat Racers 1.5.0

This release adds a three-race cup, cleans up the cats in the race view, lightens every scene, and gives the blocky mode its own identity.

## What changed

- **Cup.** Track Select has a **CUP ×3** button. It runs Desktop Dojo, Block Quarry and Glitch Core in order at the chosen level, awards 10-8-6-5-4-3-2-1 points per race, shows the points table between races and names a champion at the end.
- **Cleaner cats in the chase view.** The solid fur strands that surrounded each head rendered as grainy speckle from the race camera. They are gone. The fur shader now adds a soft pale edge and a little sky fill, so dark coats such as Zizi's keep a rounded form instead of reading as a flat silhouette.
- **Block Racers.** The blocky mode is renamed from Minecraft Racing. Its drivers are Cubby, Pixel, Mossy, Shade, Grumble, Rattle, Oink and Barter, with redrawn faces and outfits, a new kart badge, a new trackside figure and regenerated HUD portraits. Saved records carry over.
- **Lighter scenes.** Cat heads, ears, tires and shared kart shapes use lower mesh resolution; small kart trim is hidden beyond 70 m; pebble-sized scenery spheres and twig-thin cylinders use coarse meshes.
- **Desktop Dojo** has a graph-paper desk surface again, this time as a mipmapped texture that does not shimmer.
- **Dust** is smaller and sits at wheel height, so it no longer covers the karts. Glitch Core uses a cool tint.
- **Full detail** renders natively up to a 2560×1440 pixel budget and upscales beyond it, so 4K and Retina-scaled windows no longer shade four times the pixels.
- **Smaller download.** The 128 turntable frames import as lossy WebP at quality 0.85. Source PNGs are unchanged.
- **Automation.** GitHub Actions runs the test suites on every push and builds the Universal Mac app; pushing a `v*` tag publishes it as a GitHub Release.

## Measurements

Triangles drawn in the standard QA race frame, eight cat racers, measured with the game's `QA_RENDER` output:

| Course | 1.4.1 | 1.5.0 |
| --- | ---: | ---: |
| Desktop Dojo | 1.98 M | 1.12 M |
| Block Quarry | 4.97 M | 3.22 M |
| Glitch Core | 1.95 M | 1.08 M |

One cat kart is about 124,000 triangles close up (165,000 before) and about 39,000 beyond 70 m.

## Verification

- **949 counted functional checks passed** across the seven source suites, plus three temporal collision replays with zero violations, on Godot 4.7.2.
- The cup has integration checks for its start, points, track order, final ranking and exit.
- Race, menu and results screens were reviewed in captures from a software renderer and from a GitHub-hosted Mac under Metal. That virtual GPU fails to compile some shaders, so those captures are not a full visual sign-off.

## Not verified

- **Frame rate.** Hosted Mac runners gave frame times too noisy to compare builds. The triangle counts above are measured; the frame-rate gain on real hardware is not.
- **A play-through on a physical Mac** and fresh native captures. The README gallery still shows 1.4.1 captures.
- The Mac app is ad-hoc signed and not Apple-notarized.
