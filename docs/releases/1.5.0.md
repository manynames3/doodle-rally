# Doodle Rally — Cat Racers 1.5.0

This release adds a three-race cup, cleans up the cats in the race view, lightens every scene, and gives the blocky mode its own identity.

## What changed

- **Cup.** Track Select has a **CUP ×3** button. It runs Desktop Dojo, Block Quarry and Glitch Core in order at the chosen level, awards 10-8-6-5-4-3-2-1 points per race, shows the points table between races and names a champion at the end.
- **Cleaner cats in the chase view.** The solid fur strands that surrounded each head rendered as grainy speckle from the race camera. They are gone. The fur shader now adds a soft pale edge, a little sky fill, broad brushed streaks and a centre parting on the back of the head, following the supplied rear-view artwork. Dark coats such as Zizi's keep a rounded, furry form instead of reading as a flat silhouette, and Zizi's coat is a warmer brown-black.
- **Block Racers.** The blocky mode is renamed from Minecraft Racing. Its drivers are Cubby, Pixel, Mossy, Shade, Grumble, Rattle, Oink and Barter, with redrawn faces and outfits, a new kart badge, a new trackside figure and regenerated HUD portraits. Saved records carry over.
- **Lighter scenes.** Cat heads, ears, tires and shared kart shapes use lower mesh resolution; small kart trim is hidden beyond 70 m; rivet-sized kart parts, pebble-sized scenery spheres and twig-thin cylinders use coarse meshes. Pine needle tufts drop out on distant tiles while the branches stay.
- **Desktop Dojo** has a graph-paper desk surface again, this time as a mipmapped texture that does not shimmer.
- **Shadows.** The sun uses plain filtered shadows in place of a penumbra search. This removes a checker grain that covered karts standing in shadow, most visibly on Glitch Core, and is cheaper to shade.
- **Dust** is smaller and sits at wheel height, so it no longer covers the karts. Glitch Core uses a cool tint.
- **Adaptive sharpness.** Smooth motion and Balanced still start at their preset 3D scale, then adjust once a second while racing: three calm seconds sharpen the picture one step, up to native resolution; a second in which a quarter of frames run long softens it one step. The game remembers a ceiling when a sharper step proves too heavy and a floor when softening does not help, so it settles instead of hunting. A Mac with headroom reaches native sharpness about ten seconds into a race without changing a setting.
- **Full detail** renders natively up to a 2560×1440 pixel budget and upscales beyond it, so 4K and Retina-scaled windows no longer shade four times the pixels.
- **Smaller download.** The 128 turntable frames import as lossy WebP at quality 0.85. Source PNGs are unchanged.
- **Windows and Linux builds.** New export presets produce a single-file Windows build and a single-file Linux build alongside the Universal Mac app.
- **Automation.** GitHub Actions runs the test suites on every push and builds the Universal Mac app; pushing a `v*` tag publishes it as a GitHub Release.

## Measurements

Triangles drawn in the standard QA race frame, eight cat racers, measured with the game's `QA_RENDER` output:

| Course | 1.4.1 | 1.5.0 |
| --- | ---: | ---: |
| Desktop Dojo | 1.98 M | 0.87 M |
| Block Quarry | 4.97 M | 2.81 M |
| Glitch Core | 1.95 M | 0.83 M |

One cat kart is about 77,000 triangles close up (165,000 before) and about 36,000 beyond 70 m.

## Verification

- **955 counted functional checks passed** across the seven source suites, plus three temporal collision replays with zero violations, on Godot 4.7.2.
- The adaptive-sharpness rule has integration checks for sharpening, the learned ceiling, the learned floor and the preset minimum, and was run under Metal on a GitHub-hosted Mac, where it settled on all three courses.
- The exported **Linux** build passes the render smoke test for menus, all three courses, Block Racers and results. The exported **Windows** build launches on a GitHub-hosted Windows machine, falls back from Vulkan to Direct3D 12 on its own, reaches the title screen and a Desktop Dojo race, and its race capture was reviewed.
- The cup has integration checks for its start, points, track order, final ranking and exit.
- **All 38 release cases pass from source under the Forward+ renderer** with `tools/test_render.py` (software Vulkan): each exits cleanly, reaches its expected state, logs no errors and writes a screenshot. This is the same case list as the native Mac release test, without the packaged app or Metal.
- Every screen in `screenshots/1.5.0/` was rendered with the game's Forward+ renderer on a software GPU (Mesa lavapipe) and reviewed. Race views were also captured under Metal on a GitHub-hosted Mac, whose virtual GPU fails to compile some shaders.

## Not verified

- **Frame rate.** Hosted Mac runners gave frame times too noisy to compare builds. The triangle counts above are measured; the frame-rate gain on real hardware is not.
- **A play-through on physical hardware** on any platform, and native Metal captures. The gallery was rendered on a software GPU; the Windows and Linux checks ran on software graphics drivers.
- The Mac app is ad-hoc signed and not Apple-notarized.
