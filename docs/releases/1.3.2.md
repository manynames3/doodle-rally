# Doodle Rally 1.3.2

Cat Racers Track Select now has visible **Easy**, **Medium**, and **Hard** choices below the course cards. The rear-facing cat lineup gently moves its visible tails and turns its heads toward the highlighted course; **Reduced Motion** in Options stops the idle tail motion. Course and difficulty can be changed with keyboard, controller, or mouse before starting a race.

**Easy** keeps the previous default rival behavior and player handling. Medium and Hard progressively increase rival pace, acceleration, catch-up ability, and item use without increasing the player's steering penalty. Hard is designed to make a clean race competitive rather than produce an automatic win. The deterministic comparison starts each tier with the same random seed; pickup and item events can still diverge as the racers move differently.

The three-course scripted replay moves the player-versus-rival gap in the intended order on every course: Easy retains a comfortable lead, Medium narrows it, and Hard puts leading rivals ahead of the scripted player. These are repeatable balance checks, not a guarantee of finishing position for every driver.
